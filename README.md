# Tower Defense (Unity 6)

2D-гра жанру tower defense. Детальний **звіт, інструкція з установки, запуску та збірки** — у файлі **[ZVIT.md](ZVIT.md)** (українською).

**Швидкий старт**

1. Встановіть [Unity Hub](https://unity.com/download) та редактор **6000.4.5f1**.
2. Клонуйте репозиторій: `git clone https://github.com/qreqit/tower-defence-.git`
3. У Hub: **Open** → папка проєкту → відкрийте сцену `Assets/Scenes/Level1.unity`.
4. Натисніть **Play**.

Повна покрокова інструкція, опис механік і архітектури — у [ZVIT.md](ZVIT.md).
